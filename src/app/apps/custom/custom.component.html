Custom apps

Apps that are not in the Homebrew repository can be listed here with a description file. Dev Manager shows the details page, the version and an Uninstall button for them. The same file also gives the app a details page in the Installed tab.

Where to put the files

In the folder {{ dirName }} inside the app data folder: 

{{ dirPath }}

Use Open folder to open it, or Reload after you have changed a file. Each app has its own file, named <app id>.json, for example com.example.myapp.json. Files that do not end in .json are ignored.

What the file contains
FieldRequiredMeaning
idYesThe id from the app's appinfo.json. Used to find the installed app and to uninstall it.
titleYesName shown in the list.
shortDescriptionNoOne line for the list.
fullDescriptionNoText for the details page. A blank line starts a new paragraph.
iconUriNoAn https:// link to a PNG. Local paths do not work.
manifest.versionYesThe version, for example 1.0.0. Compared with the installed version to show updates.
manifest.appDescriptionNoDefaults to shortDescription.
manifest.sourceUrlNoAn https:// link shown as the project page.
manifest.ipkUrlNoAn https:// link to the .ipk. Without it, install with the Install button.

There is no separate uninstall field. Uninstall removes the app with the id from the file.
